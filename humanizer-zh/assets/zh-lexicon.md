# zh-lexicon — 中文 AI 味分级词表（Stage 1 打分 / Stage 2 删除用）

配 humanizer-zh 主流程使用。计数规则：命中数 ÷ 千字数，按层分别汇报。
**先过语境门控再计分**（SKILL.md §3.1）：黑话层只在商务/公文语境全额计分——
108 篇默认输出中赋能/抓手/闭环/深耕出现 0 次，它们是语境诱导产物【实验·
发现D】。

| 抓手、闭环、深耕、聚焦 | cn-humanizer 一级"铁证"词【研02】 |

- **实证数据**：108 篇默认输出（4 题型 × 9 模型档）中，公文黑话列全员
  **0.0/千字**【实验·findings】。社区"出现率是人类 5–20 倍"的断言无学术
  测量支撑，引用须标注属性【研02·成文提醒3】。
- **处理规则**：语境 A（商务/公文/汇报）→ 全额计分、按词处理；语境 B/C
  （默认创作/营销）→ 命中 ≈0 属预期，不为删而找；命中且承载实义（真实
  项目名、既定术语）→ 保留并记录。

## L2 衔接套话层（默认输出真正高频之一）

| 词条 | 属性 |
|---|---|
| 值得注意的是、值得一提的是、需要指出的是 | cn-humanizer 二级连接词【研02】 |
| 综上所述、总而言之、总的来说 | cn-humanizer 二级连接词【研02】 |
| 首先 / 其次 / 最后 | 作段落标头时计；真实枚举引导不计【tb-deai-style 语境判断词】 |
| 与此同时 | 委托规格补充※ |
| 一方面 / 另一方面 | 虚假平衡标记【tb-deai-style L4】 |

- **实证数据**：默认输出高频类之一；claude-sonnet-5 达 **2.95/千字**（全场
  最高），glm-5.3 为 1.57、gemini-3.7 为 1.74【实验·findings】。
- **定性依据**："首先其次总之"式衔接是"虚假逻辑连贯性的装饰"【简圣宇/
  中国社会科学报，研02】。

| 词条 | 属性 |
|---|---|
| 拓扑、克莱因瓶、第X根睫毛、青苔、赛博、齿轮、白衬衫 | 虎嗅总结的 DeepSeek 常用词（"有人总结出DeepSeek常用词"）【研02】 |
| 暗红色的瞳仁（"如果出现眼睛，那八成是'暗红色的瞳仁'"） | 虎嗅原句【研02】 |
| 伤口（0.01公分） | 虎嗅/直面AI 报道引用【研02】 |
| 涟漪、温柔、治愈、星辰 | 实验自建抒情腔词表高频项【实验】 |
| 稳稳地接住（你） | V2EX 接龙帖原句"我就在这里，不躲，不藏，不绕，不逃，稳稳地接住你"【研02】 |

- **实证数据（本层是重点）**：抒情腔是实验九档模型中**最高频的味类**——
  gemini-3.7 达 6.9/千字、deepseek-v4 为 4.81、claude-sonnet-5 为 3.76、
  最低 claude-haiku 也有 1.68【实验·findings】；新模型比旧模型更浓（Gemini
  2.5→3.7 抒情腔翻倍）【实验·发现B】；**开思维档抒情词几乎翻倍**（3.54 vs
  1.79）——抒情腔与推理深度正相关【实验·发现A】。
- **衍生亚型定性**：DeepSeek"赛博抒情散文"/李诞"科技抒情散文诗"【虎嗅，
  研02】；DoNews 从业者推测文学语料占比或达 40% 属**推测**，引用须标注
 【研02】。
- **处理规则**：按语境放宽——抒情词在营销文案语境部分是文体本身的需要
 （实验局限2）【实验】；跨模型同题对比有效，绝对值仅参考。清除手法不是
  同义词替换，是"换具体细节"（SKILL.md §5.1）。
